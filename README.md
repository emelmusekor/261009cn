# AI 직무역량 연수 원고와 실습

초등방과후학교 강사를 위한 2일·10차시 연수 자료입니다. 제공된 PPT 10개, 589장의 내용을 한 페이지에서 읽을 수 있도록 구성했습니다. 반복되는 시작·마무리 안내를 정리하고, 설명·절차·비교표·요청문·실습·확인 문항·원자료 링크를 차시 흐름에 맞게 배치했습니다.

## 페이지에서 할 수 있는 일

- PC·태블릿·휴대전화에서 10차시 원고 읽기와 목차 이동
- 원고 본문과 연결 읽을거리 검색
- 원고의 요청문 28개 복사
- 기준정보 카드로 자기소개, 메일, 안내문, 수업안, 학습지, 루브릭, 이미지, 영상, 업무 DB, 꾸러미 요청문 만들기
- 기준정보 카드와 요청문을 TXT로 내려받기
- 정보 변경 시 함께 수정할 결과물 확인
- 출결부, 서류 목록, 교차 검수표를 CSV로 내려받기
- 관련 기사·최신 동향·수업 원자료·공식 도움말 14개와 연결 차시 확인
- 연수에서 사용하는 Google·Notion 도구 바로 열기

실습 입력은 브라우저 화면에서만 처리합니다. 서버로 전송하거나 별도 저장하지 않습니다. 새로고침 전에 TXT를 내려받으면 보관할 수 있습니다. 생성 버튼은 기준정보가 담긴 요청문을 만들며, AI의 실제 답변은 요청문을 복사해 Gemini에서 받습니다.

## GitHub Pages 설정

별도 빌드나 패키지 설치 없이 정적 파일을 제공하는 사이트입니다.

1. 저장소의 **Settings → Pages**를 엽니다.
2. **Build and deployment → Source**를 **Deploy from a branch**로 선택합니다.
3. **Branch**는 **main**, 폴더는 **/(root)**를 선택하고 저장합니다.
4. 배포가 완료되면 Pages에서 표시하는 주소를 확인합니다.

기본 배포 주소: `https://emelmusekor.github.io/261009cn/`

`.nojekyll`을 포함하며, CSS·JavaScript·실습 파일은 상대 경로를 사용합니다. 저장소 이름이 붙는 프로젝트 Pages 경로에서도 동작합니다. Pages를 활성화한 뒤에는 main의 정적 파일 변경이 다음 배포에 반영됩니다.

## 내용 수정

| 파일 | 용도 |
| --- | --- |
| `content/course.json` | 차시 제목, 학습목표, 결과물, 연결 설명 |
| `content/ppt-content.json` | PPT에서 가져온 본문과 표 |
| `content/readings.json` | 읽을거리의 출처·날짜·요약·질문·연결 차시 |
| `scripts/template.html` | 공통 화면과 실습 도구 |
| `scripts/build.py` | 본문·목차·검색 자료를 HTML로 생성 |
| `styles.css` | 반응형 화면·인쇄 스타일 |
| `app.js` | 검색·요청문·복사·다운로드·필터 |
| `assets/` | 연습용 CSV 3개 |

원고나 읽을거리의 JSON을 수정한 뒤 Python 3으로 HTML을 다시 만듭니다.

```bash
python scripts/build.py
```

확인할 때에는 정적 서버로 저장소 루트를 엽니다.

```bash
python -m http.server 8000
```

## 자료 기준과 실습 파일

연수 일자: 2026.10.09–10.10. 추가 읽을거리의 확인일은 2026.10.09이며, 발표일·기사일·원문 갱신일·확인일을 구분해 표시합니다. 서비스 이름과 제공 범위는 공식 발표와 대조했습니다. Gemini 4 Argon의 발표를 일반 계정에서 즉시 사용할 수 있다는 의미로 읽지 않도록 설명을 수정했고, 계정 인증에는 복구 방법도 함께 안내합니다.

CSV의 학생 코드는 가상 데이터입니다. 출결부의 집계 수식을 유지했고, 미기록과 결석을 구분합니다. 서류 목록은 Notion으로 가져와 속성과 보기를 연습할 수 있습니다. 교차 검수표에는 인원 불일치와 장소 미기록을 일부러 넣었습니다. 기준정보를 확인하고 각 자료의 값을 고친 뒤 결과가 바뀌는지 확인합니다. CSV에는 화면 서식이 포함되지 않습니다.

수업 원자료는 원문 링크로 연결하고 추가 글은 짧게 요약했습니다. 사진·기사 전문·외부 로고를 복제하지 않았습니다. 기관 제출 서식과 실제 자료의 공유 범위는 해당 기관의 기준에 맞춥니다.
